# AgentForge implementation notes

## Decisions
- Task book v3 takes precedence over older sections of the development plan.
- Import the pinned base locally; retain this repository's origin and document history.
- Tier 1 uses one runtime process; MongoDB is the production persistence backend.
- Restricted host tools default to a dedicated workspace; Docker isolation arrives in T10.
- T15.A1+A2 (ADR-0014): every /api request needs a session; identity comes only from the HttpOnly cookie resolved server-side. scrypt instead of argon2 (no package proxy on the deploy server; the hash carries its own parameters). Ownership is an `owner_id` on every row with (owner_id, id) uniqueness, "" meaning shared-read (only the built-in agent). Mismatches answer 404, never 403. The first account is created explicitly from ADMIN_USER/ADMIN_PASSWORD; owner-less legacy rows bind to it at startup. Origin checks accept X-Forwarded-Host; Vite proxy keeps Host (changeOrigin: false) or every dev write looks cross-origin.
- ADR-0015: the login wall moved to the first turn that needs an account. An anonymous visitor gets its own `guest_` owner id (same ownership filters, nothing downstream changed) and may run GUEST_TURNS real turns, site-wide capped per day; installation routes stay 401. Signing in adopts the guest's transcript; unclaimed trials are pruned after GUEST_RETENTION_HOURS; GUEST_TURNS=0 restores the full wall.

## Verification
- 2026-10-30 Anonymous trial (ADR-0015): a visitor without a session is minted a shape-checked `guest_` id and may browse the catalogue and run GUEST_TURNS (4) real turns, charged before the model and refunded when refused, with a site-wide daily counter (`guest_usage`, unique per visitor per day) so a cleared cookie is not a new budget. Guest routes are an explicit allowlist — catalogue reads, run/session/chat-completions, approval answers, file downloads of one's own artifacts; agents/skills/MCP/sandbox/deletes stay 401 and the UI opens the sign-in dialog with a per-reason sentence. Signing in adopts the guest's sessions/traces/turns/tool_calls/checkpoints/artifacts (collision favours the guest rows on screen) and clears the cookie; `/api/auth/me` returns the budget read-only; prune_guests deletes unclaimed trials after GUEST_RETENTION_HOURS. Frontend: AuthGate no longer holds the page (loading placeholder only), LoginDialog opens over the page keeping the composer draft, sidebar footer shows trial turns or the account, session expiry degrades to the dialog instead of discarding the page. 327 backend tests pass (9 new guest-mode e2e + reworked isolation suite pinning trial vs account-only routes); ruff, tsc, i18n, ESLint and the production build pass; real-browser check (scripts/verify_guest_flow.py) confirms anonymous entry, limit dialog with draft kept, sign-in takeover.
- 2026-10-30 T15.A1+A2 auth and ownership: every /api route is refused without a session except /api/auth/* and /health; the first account is created from ADMIN_USER/ADMIN_PASSWORD (empty means nobody can log in), sessions are revocable rows keyed by token hash, passwords are scrypt-hashed, login throttles per account. Resources carry owner_id with (owner_id, id) uniqueness so two accounts can hold the same content-derived skill id; reads, resume, approval, SSE, download and skill/MCP deletion all filter by the caller, answering 404 across owners; owner-less legacy rows bind to the initial account at startup. 318 backend tests pass (12 new hashing/session tests, 9 new two-account isolation tests incl. skill-copy independence, approval cross-account refusal, artifact 404 and Origin rejection); ruff, tsc, i18n, ESLint and the production build pass. Real-browser check (scripts/verify_auth_flow.py) confirms login form gating, wrong-password error, sidebar account row, reload persistence, sign-out and mobile layout; a Vite-proxy Origin mismatch surfaced and was fixed by keeping Host (changeOrigin:false) plus X-Forwarded-Host support.
